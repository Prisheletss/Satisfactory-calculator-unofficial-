\chapter{Терминология}

\section{Конвейер}
\

Конвейер -- средство непрерывной перевозки ресурсов между двумя любыми точками.

\

Каждый конвейер характеризуется:
\begin{itemize}
	\item Формой
	
	\item Описывается системой уравнений:
		$$\vec{r}(t) = \begin{cases} x_1 = x_1(t) \\ \vdots \\ x_n = x_n(t) \\ \end{cases} \subset \ \mathbb{R}^n$$
		В частности: $\mathbb{R}^3$ (Satisfactory) или $\mathbb{R}^2$ (Factoro)
	
	\item Функцией распределения динамики скорости вдоль конвейера $v(\vec{r}, t) \cong v(t_{\text{path}}, t_{\text{time}}) = v\left(\vec{t}\right)$
	
	\item Начальной и конечной точкой: $A = \vec{r}(0), \ B = \vec{r}(t\to\text{max})$
\end{itemize}


\vspace{0.3in}


На чертежах обозначается кривой, либо отрезком, соединяющим точки A и B. Может иметь стрелки для указания направления движения, а рядом может подписываться пропускная способность
